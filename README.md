# Menu Real — código

Download: [menu-real.zip](menu-real.zip)

Conteúdo:
- `web/` — site (index.html, imagens, bibliotecas, vercel.json)
- `app/` — versão app
- `supabase/functions/` — funções `mr-ai` (Gemini) e `mr-upload`; as chaves ficam nos segredos do Supabase (`GEMINI_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`), não no código
- `apresentacao/`, `prancha/` — apresentação e áudios
